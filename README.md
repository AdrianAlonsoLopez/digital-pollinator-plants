Before running the application, execute the following commands in the terminal to install the required dependencies:
pip install flask
pip install pandas
pip install IPython

The database is included inside the .rar file so the application can run without an internet connection. However, it can also be loaded directly from Google Drive if desired.

The image paths should be updated to use the relative directory ./static/fotos/imagex.jpg. This approach will work for anyone running the code, including when it is deployed on a server.
